# Deep Fake Video Detection: BiLSTM and ResNet50

This project aims to detect deepfake videos using a hybrid deep learning approach combining ResNet50 for spatial (frame-level) feature extraction and BiLSTM for temporal pattern analysis.

## 🎯 Objectives
- Detect both lip-sync and face-swap deepfakes.
- Use frame-wise CNN features and sequence modeling for robust classification.
